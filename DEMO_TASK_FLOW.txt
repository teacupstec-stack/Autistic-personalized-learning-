================================================================================
C2 LEARNING PERSONALISATION - SAMPLE DEMONSTRATION TASK FLOW
================================================================================

This walkthrough demonstrates how an Educator ("Ms. Sarah") and a Student
("Alex") interact with the C2 Personalised Learning System.

--------------------------------------------------------------------------------
SCENARIO OVERVIEW:
--------------------------------------------------------------------------------
- Student: Alex (sim_learner_042) - Visual learner who prefers high-contrast counting.
- Setting: Classroom interactive session with teacher boundaries.
- Safety Rules: Maximum 3 consecutive misses before auto-pause; breaks are 100% free of penalty.

--------------------------------------------------------------------------------
STEP-BY-STEP DEMO FLOW:
--------------------------------------------------------------------------------

[STEP 1] LAUNCH & SELECT STUDENT
  1. Run `npm run dev` in your terminal and open http://localhost:3000.
  2. The Home Action Centre displays:
     - Active student: "Alex"
     - Counting Mastery bar
     - Session state: "Session Idle"
  3. Action: Click the student dropdown in the header to observe switching
     between "Alex", "Emma", or "Jordan". Keep "Alex" selected.

[STEP 2] TEACHER SETS BOUNDARIES (TEACHER DASHBOARD)
  1. Click "Teacher" in the top navigation or click the "Teacher Dashboard" card.
  2. Observe the "Allowed Activity Types" checkboxes:
     - [X] Easy Visual
     - [X] Easy Text
     - [X] Medium Visual
     - [X] Medium Text
  3. Action: Uncheck "Medium Text" to focus Alex strictly on Visual and Easy tasks.
  4. Notice the "Auto-Pause After Consecutive Misses" is set to 3.
  5. Action: Click "Save Settings".
     -> Confirmation badge shows: "Settings saved successfully!"

[STEP 3] DELIVER FIRST ACTIVITY (STUDENT MODE)
  1. In the "Next Question to Deliver" card, notice the SCPA Bandit has selected
     an Easy Visual question (e.g. "Count 3 Apples").
  2. Action: Click "Deliver to Student Now" or click "Student Mode" in the top bar.
  3. The Student Learning Screen loads:
     - Friendly greeting: "Hello Alex! Let's explore numbers together! 🌟"
     - Visual scene: 3 large apples displayed on the tree.
     - Interactive tip: Tap the apples directly on screen to count: 1, 2, 3!
     - Big question: "How many apples are on the tree?"
     - Three large answer buttons: [A] 2   [B] 3   [C] 4
  4. Action: Press keyboard key 'B' or click button [B] 3.
     -> Celebratory feedback appears: "⭐ Wonderful job! That is correct! ⭐"
     -> Model records Success=True, Independence=True (+1.00 reward).
  5. Action: Click "Next Fun Question! 🚀".

[STEP 4] USE HINT ASSISTANCE
  1. Next question appears (e.g., "Count 5 Stars" in night sky).
  2. Action: Click "Ask for a Friendly Hint" (or press key 'H').
     -> Friendly hint bubble expands:
        "Count them slowly one by one: 1, 2, ... up to 5!"
  3. Action: Select the correct answer 5.
     -> Model updates: Success=True, but Independence=False with minor hint penalty (+0.65 reward).

[STEP 5] STUDENT BREAK REQUEST (ZERO PENALTY)
  1. On the next task, simulate Alex feeling tired or restless.
  2. Action: Click the prominent "I Need a Break" button (or press key 'P').
     -> Screen immediately transitions to the serene Break Screen.
     -> Gentle breathing circle animates: "Inhale... Hold... Exhale..."
     -> Reassuring message:
        "✨ Taking a break does not lower your score or count as a mistake. Take as much time as you need!"
     -> Contract check: Zero penalty (0.00), streak untouched, no degradation.
  3. Action: Click "🌱 I'm Ready to Resume Learning".
     -> Session resumes immediately with no penalty.

[STEP 6] SAFETY TRIPWIRE ACTIVATION (3 MISSES IN A ROW)
  1. To demonstrate the automated safety pause, deliberately choose incorrect
     answers 3 times in a row:
     - Miss 1: Select wrong option -> Streak: 1 / 3
     - Miss 2: Click next -> Select wrong option -> Streak: 2 / 3
     - Miss 3: Click next -> Select wrong option -> Streak: 3 / 3 (Limit reached!)
  2. System automatically triggers the Safety Pause:
     -> Student screen transitions to a gentle pause:
        "Great effort, Alex! Let's pause and check in with your teacher."
     -> Automated activity selection ceases (action_id = null).
     -> Teacher Dashboard & Safety screen flash alert:
        "1-on-1 Assistance Needed for Alex (Tripwire Locked)"

[STEP 7] TEACHER ASSISTS & UNLOCKS (1-CLICK UNLOCK)
  1. Navigate to "Safety" in the top bar.
  2. Observe the status hero:
     - "Alex's Questions Are Paused (3 / 3 misses)"
     - Action: Check the box "I have checked in and helped Alex".
     - Action: Click "Unlock & Resume Student Mode 🚀".
  3. The miss streak resets to 0 / 3, and automated selection is safely restored!

[STEP 8] INSPECT AUDIT LOG & PERFORMANCE REPORTS
  1. Click "History" in the top bar:
     - View chronological stream of all DecisionEvents and OutcomeEvents.
     - Each event shows a green "Schema Valid ✔" badge.
     - Click any event row to expand the raw JSON wire payload.
  2. Click "Reports" in the top bar:
     - Review the empirical evaluation table comparing all 6 policies.
     - Inspect the 95% confidence interval error bars.
     - Confirm 0 constraint violations across all sessions.
